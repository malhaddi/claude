# 🐍 Snake

Le jeu classique du serpent, en un seul fichier HTML autonome — **zéro dépendance**.

## Jouer

Ouvre simplement `index.html` dans n'importe quel navigateur (double-clic suffit).

## Contrôles

| Action | Clavier | Mobile |
|--------|---------|--------|
| Se déplacer | Flèches, `WASD` ou `ZQSD` | glisser le doigt |
| Pause | `Espace` | bouton à l'écran |

## Règles

- Mange les pommes 🍎 pour grandir et marquer des points.
- Chaque pomme accélère un peu le serpent.
- Évite les murs et ta propre queue.
- Le meilleur score est sauvegardé localement (`localStorage`).

Fait avec Canvas + JavaScript vanilla.
